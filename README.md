# Wroot

Wroot es un prototipo estático en español para organizar billeteras, movimientos, metas, pagos recurrentes y un portafolio simulado.

## Ejecutar

Abre `WrootT.html` directamente en un navegador moderno. No requiere instalar dependencias ni ejecutar un servidor. La raíz `index.html` redirige a la aplicación para que también funcione en servicios estáticos que esperan un archivo de inicio llamado `index.html`.

## Publicar con GitHub Pages

En el repositorio, abre **Settings → Pages** y elige **Deploy from a branch**. Selecciona la rama `main` y la carpeta `/(root)`, y guarda. Cuando Pages termine la publicación, visita la URL que aparece en esa sección.

## Alcance del prototipo

El acceso es una demostración local, no una autenticación real. Los datos son de ejemplo y se mantienen solo en memoria: se pierden al recargar o cerrar la página. No conectes cuentas bancarias ni ingreses contraseñas reales. Los valores del portafolio son simulados y no constituyen asesoría financiera.
